# Competitive Research — GitHub

Research date: 2026-10-06

We searched GitHub for systems overlapping with the Opportunity Engine. The conclusion is important:

**There is no single repository found that combines evidence-backed opportunity discovery, affiliate economics, offer matching, asset selection, autonomous experimentation, and closed-loop revenue learning in the exact way we want.**

## Reusable ideas identified

- Affiliate-agent systems: specialist agents, offer schemas, ROI/performance analysis, disclosure safeguards.
- Opportunity-mining systems: evidence-backed opportunity cards, buyer hypotheses, WTP signals, validation plans.
- OpenGSC-style systems: first-party search evidence, historical snapshots, content decay, cannibalization, outcome windows, MCP interfaces.
- SEO audit pipelines: rerunnable/idempotent workers and persisted intermediate outputs.
- Product intelligence systems: normalized product catalogs, comparison, price/freshness tracking, affiliate attribution.
- Semantic SEO systems: provenance and anti-fabrication guards.

## Architecture consequence

The project is not an affiliate content farm. Its proprietary core is the feedback graph:

Evidence -> Opportunity -> Offer -> Asset -> Experiment -> Outcome -> Learning

## Licensing

Open-source repositories are references. Code reuse requires checking the source license and preserving required notices. No proprietary code will be copied.
