# Live Benchmark

The live benchmark is the production-facing evidence gate.

Flow: GitHub Issues -> normalization -> deduplication -> commercial intent -> opportunity clustering -> offer matching -> deterministic score -> top 10.

Default query slate:
- is:issue is:open comments:>=2 pricing alternative
- is:issue is:open comments:>=2 "feature request" integration
- is:issue is:open comments:>=2 manual workflow
- is:issue is:open comments:>=2 hosted dashboard
- is:issue is:open comments:>=2 enterprise authentication

A run must report raw evidence, unique evidence, duplicates, opportunities, top 10, evidence URLs, offer verification dates, and rejected/insufficient-signal counts.

GitHub pain is evidence of pain, not proof of willingness to pay. Autonomous publishing, outreach, purchases, account creation, or ad spend require a separate approved validation experiment.

The seed offer catalog contains only affiliate programs checked against official merchant pages and must be re-verified before execution.
