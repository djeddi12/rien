# Next Best Action

The system should eventually answer one operational question:

> What is the highest-value action we should take next?

A candidate action is evaluated on:

- expected commercial value
- evidence confidence
- probability of conversion
- execution effort
- time to signal
- strategic learning value
- downside/risk
- freshness of evidence

A high-revenue but poorly evidenced opportunity should not automatically beat a smaller but highly validated opportunity.

The output must include:
1. action
2. opportunity
3. evidence
4. expected outcome
5. success metric
6. stop condition
7. confidence
8. reason for ranking
