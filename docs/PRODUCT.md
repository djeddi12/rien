# Product Definition

## Problem

Most affiliate systems publish content first and hope demand appears. This project reverses the order.

It asks:

> Where is there measurable demand, commercial intent, a monetizable solution, and an execution gap worth attacking now?

## First MVP

The first working version should be able to:

1. Accept an opportunity candidate.
2. Store its evidence.
3. Calculate a deterministic score.
4. Match candidate offers.
5. Generate an execution plan.
6. Explain the decision using Qwen when configured.
7. Record the eventual result.
8. Update opportunity memory.

## Example

Candidate:
"best CRM for AI agencies"

Evidence:
- demand signal
- commercial-intent evidence
- competitor coverage
- offer economics
- content gaps
- SERP observations
- execution estimate

Output:
- score
- confidence
- reasons
- recommended monetization
- recommended asset bundle
- risks
- next action

## Asset bundle

A high-value opportunity may produce:

PAGE + COMPARISON + TOOL + CTA + VIDEO BRIEF

The engine decides which assets are justified by evidence instead of generating everything automatically.
